# DBD 2.0

A rebuilt website for [Driven by Design Creative Agency](https://dbdcreativeagency.com/) — Michael L. Clay’s multimedia visual storytelling studio.

The original site mixed a personal résumé timeline, unfinished shop pages, and leftover theme copy. This version leads with the work, three audiences (organizations, schools, families), and a clear way to hire or buy.

## Pages

- `/` Home
- `/work` Photography, film, and community archive
- `/hire` Photography and film services with corrected prices
- `/programs` Art of Visual Storytelling, Creator’s Corner, Finding My Niche’
- `/story-driven` Board game, life-size events, FAQ
- `/books` *I Found a Reason to Speak* and Uncle Mike & Me
- `/shop` Story Driven and classes
- `/about` Biography, selected timeline, testimonials
- `/contact` Inquiry form

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Photographs and product images are Michael’s, drawn from the live studio archive. Contact still uses the public studio email and phone from the current site.
